# Creative guide

## Default carousel composition

Use 4-10 slides unless the user specifies a different length.

Typical sequence:
1. Cover / hook
2. Context or problem
3-7. Main ideas/examples
8-9. Implication or framework
10. Takeaway / CTA

## GPT Image 2 briefs

Each slide brief should specify:
- purpose of the slide;
- exact on-slide text, if any;
- composition and visual hierarchy;
- brand colors/fonts by descriptive rule or supplied reference;
- desired aspect ratio/resolution;
- what must not appear.

Prefer generating one slide per request when text fidelity or layout consistency is important. Use reference images where the user has provided approved brand examples.

## Consistency

- Keep layout system, margins, typography hierarchy, and illustration/photo treatment consistent across a carousel.
- Do not invent logos; use provided brand assets when logos are required.
- Avoid visual clutter.
- Check generated text for errors before building the PDF.
